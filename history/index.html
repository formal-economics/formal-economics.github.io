Fingerprints

Each commit has a fingerprint: a 40-character hash computed from the full content of the library at that moment and from the fingerprint of the commit before it. Change a single character anywhere in the past, and every later fingerprint changes. A fingerprint therefore stands for one exact state of the library and all of its history.

The list of every commit, its fingerprint and its timestamp, oldest first, is published here as plain text. When the repository is public, each line can be checked against it, for example with git log --format="%H %cI"; the push of 20 September 2026 to GitHub’s servers is an independent witness that every commit up to it existed by then.
