Definition Choice and rationalizability Rubinstein (2012)

Definition

A choice function CCC for a context (X,D){(X, D)}(X,D) satisfies condition α\alphaα if for all A,B∈D{A, B \in D}A,B∈D with A⊂B{A \subset B}A⊂B and C(B)∈A{C(B) \in A}C(B)∈A, we have C(A)=C(B){C(A) = C(B)}C(A)=C(B).

Assumptions

  • CCC is a choice function for a context (X,D){(X, D)}(X,D). Matches the source

Intuition

If the winner of a large tournament also plays in a smaller one, it should win there too: removing alternatives that were not chosen cannot change the choice.
