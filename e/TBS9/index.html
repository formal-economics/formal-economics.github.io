Definition

Production functions and technologies

In the single-output case, a technology and a production function can each be derived from the other.

Source
Rubinstein, Lecture Notes in Microeconomic Theory Lecture 6: More Economic Agents, p. 89
Field

Definition Producers and the firm Rubinstein

01Statement

Definition. Consider the single-output case: commodity K is produced from commodities 1,…,K−1, i.e. every z∈Z has zK​≥0 and zk​≤0 for k=K.

  1. From a technology Z, the production function is f(v)=max{x:(−v,x)∈Z} for input vectors v∈R+K−1​.
  2. From a production function f, the derived “technology” is Z(f)={(−w,x):x≤f(v) and w≥v for some v∈R+K−1​}.

Technical conditions 2 · needed only to state it formally
  • The commodities are indexed so that the last one is the output.
  • The maximum defining f(v) is assumed to be attained for every input vector v.

Intuition

With a single output, f(v) is the largest output the inputs v can produce, so the frontier of the technology is the graph of f; conversely, Z(f) rebuilds a technology from f by allowing more inputs and less output.
