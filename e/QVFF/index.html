Quasi-linearity in all commodities

Every good acts like money: adding a common amount of any good preserves comparisons.

Definition Consumer preferences Rubinstein (2012)

Definition

A preference relation ≿\succsim≿ on X=R+K{X = \mathbb{R}^K_+}X=R+K​ is quasi-linear in all commodities if for every commodity kkk, all bundles x,y{x, y}x,y and every real ε\varepsilonε for which x+εek{x + \varepsilon e_k}x+εek​ and y+εek{y + \varepsilon e_k}y+εek​ are bundles: x≿y{x \succsim y}x≿y implies x+εek≿y+εekx + \varepsilon e_k \succsim y + \varepsilon e_kx+εek​≿y+εek​, where eke_kek​ is the unit vector of commodity kkk.

Assumptions

  • The commodity space is X=R+K{X = \mathbb{R}^K_+}X=R+K​, bundles of KKK goods. Matches the source
  • ≿\succsim≿ is a preference relation on XXX. Matches the source
  • The condition is required for every commodity kkk and every real ε\varepsilonε. Matches the source
Technical conditions (1)needed only to state it formally
  • The shifted bundles must lie in R+K{\mathbb{R}^K_+}R+K​, so that the comparison is defined.

Intuition

Every good behaves like money: comparisons are unaffected by adding or removing a common amount of any single good.
