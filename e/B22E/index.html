Claim Rubinstein (2012), Lecture 2, p. 13

B22E

Utility is ordinal: strictly increasing transformations

Composing a utility function with any strictly increasing function gives another representation of the same preference.

Machine-checked Utility representation D11D01
Result Utility representation Rubinstein (2012)

Claim

Let ≿\succsim≿ be a preference relation on XXX, let U:X→R{U : X \to \mathbb{R}}U:X→R represent ≿\succsim≿, and let f:R→Rf : \mathbb{R} \to \mathbb{R}f:R→R be strictly increasing. Then V=f∘U{V = f \circ U}V=f∘U also represents ≿\succsim≿.

Assumptions

  • ≿\succsim≿ is a preference relation on XXX. Matches the source
  • UUU represents ≿\succsim≿. Matches the source
  • f:R→Rf : \mathbb{R} \to \mathbb{R}f:R→R is strictly increasing. Matches the source

Conclusion

x≿y  ⟺  f(U(x))≥f(U(y))x \succsim y \iff f(U(x)) \ge f(U(y))x≿y⟺f(U(x))≥f(U(y)) for all x,y∈X{x, y \in X}x,y∈X.

Intuition

A strictly increasing fff preserves and reflects the order of real numbers, so the ranking encoded by UUU is untouched. Utility is ordinal.
