Convexity and quasi-concave utility

A represented preference is convex exactly when its utility function is quasi-concave.

Machine-checked Consumer preferences D11
Result Consumer preferences Rubinstein (2012)

Claim

Let ≿\succsim≿ be a preference relation on X=R+K{X = \mathbb{R}^K_+}X=R+K​ and let u:X→R{u : X \to \mathbb{R}}u:X→R represent ≿\succsim≿. Then ≿\succsim≿ is convex if and only if uuu is quasi-concave, that is, for every y∈X{y \in X}y∈X the set {x∈X:u(x)≥u(y)}{\{x \in X : u(x) \ge u(y)\}}{x∈X:u(x)≥u(y)} is convex.

Assumptions

  • ≿\succsim≿ is a preference relation on X=R+K{X = \mathbb{R}^K_+}X=R+K​. Matches the source
  • u:X→R{u : X \to \mathbb{R}}u:X→R represents ≿\succsim≿. Matches the source

Conclusion

≿\succsim≿ is convex   ⟺  \iff⟺ uuu is quasi-concave.

Intuition

Under a representation, the upper contour set of ≿\succsim≿ at yyy is exactly {x:u(x)≥u(y)}{\{x : u(x) \ge u(y)\}}{x:u(x)≥u(y)}, so convexity of the preference and quasi-concavity of the utility are the same condition.
