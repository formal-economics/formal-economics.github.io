Definition

The default-bias procedure

Maximize utility, but give the default a non-negative bonus.

Rubinstein, Lecture 3: Choice, p. 39 Behavioral decision theory · JEL D91, D81 Entry 4JBW Citec

01Statement

Definition. Let u:X→R be a utility function and β:X→R a bias function with β(x)≥0 for all x, and assume that the procedure below selects exactly one alternative for every pair (A,a). The default-bias procedure DBPu,β​ chooses from (A,a)

  • the alternative x∈A∖{a} that uniquely maximizes u on A∖{a}, if u(x)>u(a)+β(a);
  • the default a, if u(a)+β(a)≥u(x) for every x∈A∖{a}.

Intuition

The default enjoys a bonus β(a): the decision maker moves away from it only when some alternative beats it by more than the bonus. Status-quo bias is modeled as a utility premium for the default.
