Problem 6 Easy

Properties of the cost function and Shephard’s lemma

The cost function is homogeneous of degree one and concave in input prices, nondecreasing in the price of an input never used negatively; its derivatives are input demands.

01The problem

Hide every answer, then reveal them one part at a time.

With L inputs, a producer makes K−L outputs. Input prices form the vector w. Write C(w,y) for the cheapest way to make the output vector y, and ak​(w,y) for the amount of input k demanded. Prove each claim:

  1. a

    C(λw,y)=λC(w,y);

    Machine-checked statement

    The cost function is homogeneous of degree one in input prices#

    Answer

    Shown: C(λw,y)=λC(w,y).

    For a technology Z⊆RK with inputs 1,…,L and outputs L+1,…,K, let C(w,y)=mina​{w⋅a:(−a,y)∈Z} be the least cost of producing y∈R+K−L​ at input prices w. For w≫0 and λ with λw≫0 (that is, λ>0),

    C(λw,y)=λC(w,y).
    The assumptions of the statement, each beside the line of the Lean statement that states it
    Number As the problem states it Correspondence In Lean
    1 Input prices are positive: w≫0 and λw≫0. (hw : ∀ i, 0 < w i) (hlamw : ∀ i, 0 < lam * w i) Matches the source

    An assumption of the source, stated in Lean

    The assumption is stated by the line of Lean beside it.

    Technical conditions needed only to state it formally
    • The numbers of inputs and outputs are arbitrary; either may be zero.
    • The cost is taken for some technology Z⊆RK; none of the usual assumptions on technologies is imposed.
    • Output vectors are nonnegative: y∈R+K−L​.
    • The minima defining C(w,y) and C(λw,y) are attained.

    Intuition

    Scaling all input prices by λ scales the cost of every feasible input vector by λ, so the cheapest vector stays the cheapest.

  2. b

    raising any single input price wk​ never lowers C;

    1 As printed

    The cost function is nondecreasing in each input price#

    Answer

    As printed, this does not hold in full generality, because nothing stops a feasible input vector from having a negative component. Counterexample: one input and one output, y=0, and a technology in which the feasible input amounts are a∈{−1,−2}. At the price w=1 the least cost is −2; at the higher price w′=2 it is −4. The corrected statement adds that input k is never used in a negative amount.

    For a technology Z⊆RK with inputs 1,…,L and outputs L+1,…,K, let C(w,y)=mina​{w⋅a:(−a,y)∈Z} be the least cost of producing y∈R+K−L​ at input prices w. Original claim: raising one input price wk​ never lowers C; that is, when wk​≤wk′​ and wj​=wj′​ for all j=k, we get C(w,y)≤C(w′,y).

    Assumptions and the Lean statement

    Intuition

    A negative amount of an input is an amount the producer supplies. When its price rises, supplying it pays more, so the cost of producing the output can fall.

    2 Corrected statement

    Cost is nondecreasing in a price when that input is never negative#

  3. c

    C is a concave function of w;

    Machine-checked statement

    The cost function is concave in input prices#

  4. d

    Shephard’s lemma: when C is differentiable, ∂C/∂wk​(w,y)=ak​(w,y);

    Machine-checked statement

    Shephard’s lemma: the price derivative of cost is input demand#

  5. e

    when C has continuous second derivatives, ∂ak​/∂wj​(w,y)=∂aj​/∂wk​(w,y) for every pair of inputs j,k.

    Machine-checked statement

    Cross-price effects on input demands are symmetric#
