Definition

Weak axiom for choice with defaults

A revealed-preference consistency condition adapted to choice problems with a default.

Rubinstein, Lecture 3: Choice, p. 40 Behavioral decision theory · JEL D91, D81 Entry H4YY Citec

01Statement

Definition. An extended choice function c satisfies the weak axiom (WA) if for all sets A,B and all distinct a,b∈A∩B:

  1. it is not the case that c(A,a)=a and c(B,a)=b;
  2. for all defaults x∈A and y∈B outside {a,b} (not necessarily distinct), it is not the case that c(A,x)=a and c(B,y)=b.

Intuition

Pattern 1: if a is kept when it is the default in A, it cannot be abandoned for b when it is the default in B. Pattern 2: when neither alternative is the default, the comparison between a and b cannot be reversed from one set to another.
