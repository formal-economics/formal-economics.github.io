Definition

Choice function

A choice function selects one alternative from every menu in its domain.

Source
Rubinstein, Lecture Notes in Microeconomic Theory Lecture 3: Choice, p. 24
Field
Choice and rationalizability Part I, Individual choice · JEL D01, D11

01Statement

Definition. Given a context (X,D), a choice function C assigns to every A∈D an element C(A)∈A.

The assumptions of the statement, each beside the line of the Lean statement that states it
Number As Rubinstein states it Correspondence In Lean
1 (X,D) is a context: D is a set of nonempty subsets of X. (ctx : Context X) Matches the source
2 C assigns exactly one element to every A∈D. Stated by the Lean statement as a whole Matches the source
3 The chosen element belongs to the problem: C(A)∈A. Stated by the Lean statement as a whole Matches the source

an assumption of the source, stated in Lean stated by the Lean statement as a whole

1 of 3 assumptions are wired to the line of Lean that states them; the Lean statement below states the others as a whole.

Intuition

A choice function is pure behavior: it records what is chosen from each menu, with no reference to preferences or motives.
