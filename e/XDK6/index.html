Path independence

Rational choice is path independent; path independence gives condition α once every subset is a choice problem, but not rationalizability.

Problem Choice and rationalizability Rubinstein

01The problem4 parts

Hide every answer, then reveal them one part at a time.

A choice correspondence C satisfies path independence if for every set A and every partition of A into nonempty disjoint A1​ and A2​, C(A)=C(C(A1​)∪C(A2​)); the definition applies also to choice functions.

Corrected statement 1 of 3

Path independence, imposed where the sets lie in the domain#

Answer

Machine-checked under this reading: (a), (b) and (d) as printed, and (c) with the added full-domain condition. On an arbitrary domain, (c) does not hold in this reading.

Path independence asks that C(A)=C(C(A1​)∪C(A2​)) whenever a choice problem A∈D is split into nonempty disjoint A1​,A2​ (for a choice function, C(A1​)∪C(A2​) is {C(A1​),C(A2​)}). The equation needs A1​, A2​ and C(A1​)∪C(A2​) to lie in the domain D; the printed definition does not say what happens when they do not.

In this reading the equation is imposed only for partitions with A1​, A2​ and C(A1​)∪C(A2​) in D. Then:

  • (a) for every preference relation ≿ whose sets of best elements are nonempty on D, the rational correspondence C≿​, which chooses the ≿-best elements of each problem, is path independent;
  • (b) some choice function, on some context, is not path independent;
  • (c) if D contains every nonempty subset of X, every path-independent choice function satisfies condition α: A⊂B and C(B)∈A imply C(A)=C(B);
  • (d) some path-independent choice correspondence is not rationalizable.

The 2 definitions it is stated with

Intuition

Under this reading a sparse domain can make path independence hold vacuously: if no two choice problems in D are disjoint, no partition is ever tested. It can say something about condition α only once the domain contains the pieces needed to split a problem. For (d), choosing both elements of every pair but only part of a triple is path independent yet not rationalizable.

Corrected statement 2 of 3

Path independence with the pieces required to lie in the domain#

Answer

Machine-checked under this reading: (c) and (d) as printed, and (a) with the added full-domain condition. On an arbitrary domain, (a) does not hold in this reading.

Path independence asks that C(A)=C(C(A1​)∪C(A2​)) whenever a choice problem A∈D is split into nonempty disjoint A1​,A2​ (for a choice function, C(A1​)∪C(A2​) is {C(A1​),C(A2​)}). The equation needs A1​, A2​ and C(A1​)∪C(A2​) to lie in the domain D; the printed definition does not say what happens when they do not.

In this reading, for every A∈D and every partition of A into nonempty disjoint A1​,A2​, the sets A1​, A2​ and C(A1​)∪C(A2​) are required to belong to D, and C(A)=C(C(A1​)∪C(A2​)). Then:

  • (a) if D contains every nonempty subset of X, the rational correspondence C≿​ of any preference relation with nonempty best sets on D is path independent;
  • (c) every path-independent choice function satisfies condition α, on any domain;
  • (d) some path-independent choice correspondence is not rationalizable.
Assumptions and the Lean statement

Intuition

Requiring the pieces to be choice problems makes path independence demanding on a small domain — even a rational decision maker cannot meet it if the pieces are missing. In exchange it always delivers condition α, because the needed partition is guaranteed to be available.
