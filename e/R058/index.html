Problem Choice and rationalizability Rubinstein

The problem

Choice is made from a list rather than a set: a list is a nonempty finite sequence of elements of X, so ⟨a,b⟩, ⟨a,a,b⟩ and ⟨b,a⟩ differ. A choice function assigns to each list one of its elements; it satisfies Property I if C(⟨L1​,…,Lm​⟩)=C(⟨C(L1​),…,C(Lm​)⟩).

Machine-checked statement

Choice from lists: Property I and its relatives#

Answer

All four are machine-checked; (b) is proved in one direction only, as asked. The interpretation requested in (a) is not formalized, and the characterization of part (c) is a separate entry.

A list is a nonempty finite sequence of elements of X, and a list choice function C picks an element of each list. C satisfies Property I if C(⟨L1​,…,Lm​⟩)=C(⟨C(L1​),…,C(Lm​)⟩) for all lists L1​,…,Lm​, where ⟨L1​,…,Lm​⟩ is their concatenation. C satisfies Order Invariance if reordering a list leaves the choice unchanged, and Duplication Invariance if deleting an element that appears elsewhere in the list leaves the choice unchanged. Given a one-to-one u:X→R, C accommodates a longer list if u(C(L′))≥u(C(L)) whenever L′ extends L (that is, L′=⟨L,M⟩ for a list M), with strict inequality for some such pair.

  • (a) Some list choice function on a finite X satisfies Property I, and some list choice function on a finite X violates it.
  • (b) Every list choice function satisfying Duplication Invariance satisfies Order Invariance, for any X.
  • (d) On some finite X, with a one-to-one u, some list choice function accommodates a longer list.
  • (e) On some finite X, with a one-to-one u, some list choice function satisfies Property I but does not accommodate a longer list.

The 7 definitions it is stated with

Intuition

Property I is path independence for lists: choose within consecutive blocks, then choose among the block winners. Duplication Invariance makes the choice depend only on which elements appear, and reordering does not change that. The converse fails: picking the most frequent entry, with a fixed tie-break, ignores order but not duplicates.

  1. (a)

    Interpret Property I; give two examples of choice functions that satisfy it and two that do not.

    Machine-checked statement 1 of 2

    Two different list choice functions with Property I#

    Answer

    Proved: the two requested examples exist.

    A list is a nonempty finite sequence of elements of X, and a list choice function C picks an element of each list. C satisfies Property I if C(⟨L1​,…,Lm​⟩)=C(⟨C(L1​),…,C(Lm​)⟩) for all lists L1​,…,Lm​, where ⟨L1​,…,Lm​⟩ is their concatenation.

    On some finite set X there are two list choice functions C1​,C2​, differing on some list, both satisfying Property I.

    The 2 definitions it is stated with

    Intuition

    Maximizing a fixed ranking of X satisfies Property I — the best element of the whole list is also the best among the block winners — and different rankings give different choice functions.
