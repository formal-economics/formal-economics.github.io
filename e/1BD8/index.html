Proposition

Characterization of the default-bias procedure

On a finite set, the weak axiom and default tendency characterize choice that maximizes utility with a bonus for the default.

01Statement

Proposition. Let X be finite and let c be an extended choice function on X. Then c satisfies WA and default tendency if and only if c=DBPu,β​ for some utility u:X→R and some bias β:X→R with β≥0 for which the procedure is well defined.

Conclusion

c satisfies WA and DT ⟺ c is a default-bias procedure. The “if” direction holds on any set X, finite or not.

The definition it is stated with

Intuition

WA and DT are what one observes from someone who maximizes a stable utility but gives the default a bonus. Conversely, the utility and the bonus can be recovered from choices: the proof ranks every alternative both as a default and as a non-default, and represents that ranking numerically.
