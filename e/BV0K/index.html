Rationalizability on union-closed domains

On a domain closed under unions, condition α suffices for rationalizability.

Rubinstein, Lecture 3: Choice, pp. 28–29 Choice and rationalizability · JEL D01, D11 Entry BV0K Citec

01Statement

Proposition. Let C be a choice function for a context (X,D) in which A∪B∈D whenever A,B∈D. If C satisfies condition α, then C can be rationalized.

The assumptions of the statement, each beside the line of the Lean statement that states it
Number As Rubinstein states it Correspondence In Lean
1 C is a choice function for a context (X,D). (C : ChoiceFunction ctx) Matches the source
2 D is closed under unions of two problems. (hunion : ∀ A B : Set X, A ∈ ctx.domain → B ∈ ctx.domain → A ∪ B ∈ ctx.domain) Matches the source
3 C satisfies condition α. (hα : C.SatisfiesConditionAlpha) Matches the source
⇒ Then C is rationalizable. C.IsRationalizable

an assumption of the source, stated in Lean

Each assumption is stated by the line of Lean beside it. Point at a row to find its line in the full statement below.

Intuition

Say x is revealed above y when x is chosen from a problem containing y. Because two problems can always be merged into one, revealed comparisons can be confronted with each other; condition α then rules out cycles, and the revealed relation extends to a complete preference.
