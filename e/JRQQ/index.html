Problem 9 after Luce (1959)

Luce's choice axiom

Path independence of choice probabilities forces the Luce model, in which each alternative is chosen with probability proportional to a fixed weight.

As printed, this statement does not hold in full generality; a corrected companion is proved.

Problem Choice and rationalizability Rubinstein

The problem

A probabilistic choice function assigns C(a∣A)>0 to every a∈A⊆X, with ∑a∈A​C(a∣A)=1; for B⊂A let C(B∣A)=∑a∈B​C(a∣A). It satisfies path independence (PI) if C(a∣A)=C(a∣B)C(B∣A) for any a∈B⊂A.

1 As printed

Choice probabilities sum to one on every subset#

Answer

As printed, the definition cannot be met: the normalization also applies to A=∅, where the sum is 0, so no function satisfies it, on any set X. The corrected definition imposes the normalization on nonempty menus only.

A probabilistic choice function on a set X assigns a number C(a∣A)>0 to every a∈A and every A⊆X, with, for every A⊆X,

a∈A∑​C(a∣A)=1.
The Lean statement

Intuition

Choice probabilities are only meaningful for menus that contain something to choose.

2 Corrected statement

Luce's choice axiom yields the ratio representation#

Answer

(a) Proved: PI is a genuine restriction. (b) Proved: PI implies the Luce representation. Uniqueness of v and the converse implication are not part of the statement.

A probabilistic choice function assigns C(a∣A)>0 to each a∈A⊆X, with ∑a∈A​C(a∣A)=1 for every nonempty A; write C(B∣A)=∑a∈B​C(a∣A). It satisfies path independence (PI) if, whenever a∈B⊆A,

C(a∣A)=C(a∣B)C(B∣A).
  • (a) Some probabilistic choice function violates PI.
  • (b) If C satisfies PI, there is v:X→(0,∞) such that, for every menu A and every a∈A,
C(a∣A)=∑x∈A​v(x)v(a)​.

The 3 definitions it is stated with

Intuition

PI says the odds of choosing a over b do not depend on what else is on the menu. Fix a reference alternative, define each alternative’s weight by its odds against it, and the ratio formula follows.
