Standard convexity as Ψ-convexity

On a convex, closed subset of ℝᴺ, a continuous preference is convex in the usual sense exactly when it is Λ-convex for the linear orderings x ↦ v · x.

Example. Let X be a convex and closed subset of RN. Each nonzero vector v defines the algebraic linear ordering x≥v​y if v⋅x≥v⋅y; let Ψ be the set of all of them. A preference ≿ on X is convex in the standard sense if a≿b implies αa+(1−α)b≿b for every α∈[0,1]. Then, for a continuous preference ≿ on X, standard convexity is equivalent to Ψ-convexity in the sense of Definition 1.

The 3 definitions it is stated with

Intuition

If b is not weakly better than a, Ψ-convexity asks for a linear functional that ranks b strictly below every alternative weakly better than a. For a continuous preference that set is closed, so such a separating hyperplane exists exactly when the set is convex.
