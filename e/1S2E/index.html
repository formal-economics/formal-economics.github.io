1S2E

Who pays more for information?

Is a more risk-averse agent ready to pay more to learn the state of nature? Under expected utility it could go either way, and both cases are exhibited.

Machine-checked Risk attitudes D81
Problem Risk attitudes Rubinstein (2012)

The question

An agent chooses between actions x{x}x and y.{y}.y. Each yields a certain monetary prize that depends on the state of nature, which is A{A}A with probability α{\alpha}α and B{B}B with probability 1−α.{1-\alpha}.1−α. The agent maximizes expected utility. Without knowing the state he would choose x;{x};x; knowing it, he would choose x{x}x in state A{A}A and y{y}y in state B.{B}.B. Discuss the statement: if agent 1 is more risk averse than agent 2, then he is ready to pay more to know the state of nature. Under the expected-utility model, is the statement always true (prove it), always false (prove it), or could it go either way (explain)?

(T1)

Machine-checked statement

Actions x{x}x and y{y}y pay (xA,xB){(x_A,x_B)}(xA​,xB​) and (yA,yB){(y_A,y_B)}(yA​,yB​) in states A{A}A (probability α{\alpha}α) and B.{B}.B. Two agents maximize expected utility; each weakly prefers x{x}x without information, and x{x}x in state A{A}A and y{y}y in state B{B}B with it. We say an agent is ready to pay v{v}v for the information if he weakly prefers the informed prospect with v{v}v deducted, α[xA−v]⊕(1−α)[yB−v],{\alpha[x_A-v]\oplus(1-\alpha)[y_B-v]},α[xA​−v]⊕(1−α)[yB​−v], to the uninformed α[xA]⊕(1−α)[xB].{\alpha[x_A]\oplus(1-\alpha)[x_B]}.α[xA​]⊕(1−α)[xB​]. Let agent 1 be more risk averse than agent 2: whenever agent 1 weakly prefers a lottery to a sure amount, so does agent 2. Then:

  • (i) in some instance there is a fee that agent 2 is ready to pay and agent 1 is not;
  • (ii) in another instance agent 1 is ready to pay every fee that agent 2 is ready to pay.
Technical conditions (1)needed only to state it formally
  • The four prizes, and the prizes net of a fee, lie in the set of monetary prizes under consideration.

Answer · in our words

It could go either way: more risk aversion neither always raises nor always lowers the amount an agent is ready to pay to learn the state. Readiness to pay is our formulation of the printed phrase.

Intuition

Learning the state lets each agent replace the prize xB{x_B}xB​ by yB.{y_B}.yB​. Depending on the prizes, that makes the prospect safer or riskier, so a more risk-averse agent may value the information more or less.
