01The problem

Hide every answer, then reveal them one part at a time.

The source states this problem in the parts below.

  1. a

    Check the differentiability of the lexicographic preferences in R2.

    Machine-checked statement

    The lexicographic preference is not differentiable#

    Answer

    Not differentiable. At an interior bundle, D(x) is the open half-plane {d1​>0} together with the ray {d1​=0, d2​>0}, and no set of the form {d:d⋅v>0} has that shape.

    For a preference ≿ on X=R+K​ and a bundle x, D(x) is the set of improvement directions: vectors d such that, for some λ∗>0, x+λd∈X and x+λd≻x for all λ∈(0,λ∗). In the book’s sense, ≿ is differentiable if at every x there is a value vector v(x)∈R+K​ such that D(x) is the set of directions d with d⋅v(x)>0, among those that keep x+λd in X for small λ>0.

    The lexicographic preference on R+2​, x≿L​y⟺x1​>y1​ or (x1​=y1​ and x2​≥y2​), is not differentiable: at some bundle x, no value vector v(x) describes D(x).

    Intuition

    A lexicographic consumer has no rate at which good 2 trades against good 1: any gain in good 1 outweighs every loss of good 2, so the improving directions are a half-plane with one edge ray attached.

  2. b

    Assume that ≿ is monotonic, convex and differentiable, and that for every x, (*) D(x)={d:x+d≻x}. What can you say about ≿?

    Machine-checked statement

    Improvements as directions: flat indifference sets#

    Answer · in our words

    The characterization (our answer; the book asks what can be said about ≿): the indifference sets are flat — every strict upper contour set is an open half-space with a nonnegative, nonzero normal v(x), which may vary with x.

    For a preference ≿ on X=R+K​ and a bundle x, D(x) is the set of improvement directions: vectors d such that, for some λ∗>0, x+λd∈X and x+λd≻x for all λ∈(0,λ∗). In the book’s sense, ≿ is differentiable if at every x there is a value vector v(x)∈R+K​ such that D(x) is the set of directions d with d⋅v(x)>0, among those that keep x+λd in X for small λ>0.

    Let ≿ on R+K​ be monotonic, convex and differentiable, and let F(x)={d:x+d∈X} be the feasible full steps from x. Then ≿ satisfies condition (*), D(x)∩F(x)={d∈F(x):x+d≻x} at every x, if and only if it has flat indifference sets: for every x there is v∈R+K​, v=0, with

    {y:y≻x}={y:v⋅y>v⋅x}.

    As the problem states it

    1. 1 ≿ is monotonic: x≥y coordinatewise implies x≿y, and xk​>yk​ for all k implies x≻y.
    2. 2 ≿ is convex: x≿y and α∈(0,1) imply αx+(1−α)y≿y.
    3. 3 ≿ is differentiable in the book’s sense.
    4. 4 Added condition Condition (*) compares only full steps d with x+d∈X. Without this restriction the equality D(x)={d:x+d≻x} cannot hold for a monotonic, differentiable preference on R+2​, even at the bundle (1,1).

    The Lean statement below states these assumptions together.

    The definitions it is stated with

    Intuition

    Condition (*) says that whether a step improves can be read off its direction alone, so there is no curvature that lets a long step improve while short steps do not. Together with convexity this flattens every upper contour set to a half-space.

  3. c

    For monotonic, convex and differentiable ≿, let E(x) be the set of directions d for which some ε∗>0 gives x+εd≺x for all 0<ε≤ε∗. Show that {−d:d∈D(x)}⊆E(x), but not necessarily with equality.

    1 As printed

    Negated improvement directions worsen, at every bundle#

    2 Corrected statement

    At interior bundles, negated improvement directions worsen#

    Machine-checked statement

    Worsening directions can be more than negated improvements#

  4. d

    For two commodities, let u(x1​,x2​)=x1​+x2​ if x1​+x2​≤1 and 1+2x1​+x2​ otherwise. Show that these preferences are not continuous, yet monotonic, convex and differentiable.

    Machine-checked statement

    A discontinuous preference that is monotone, convex and differentiable#
