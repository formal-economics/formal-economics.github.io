About

Download the library as open data

Every entry of the library in one JSON file, for research, teaching or your own tools.

The shape of an entry Edition of 18 October 2026

Files

Open data: plain JSON and text, regenerated with each edition of the site.

  • JSON catalogue.json Every entry, with its statements and assumptions; the sources and the topics. About 539 KB Download
  • JSON relations.json What implies what: the notions and the machine-checked relations between them, each with the tag of the entry that proves it. About 128 KB Download
  • TXT commits.txt The fingerprint and timestamp of every commit of the Lean library, oldest first. Plain text Open →

What the files do not hold: the Lean code itself, which is published with the library’s repository, and the project’s working notes. Identifiers are the public tags, topic names and source names used on this site. The fingerprints are explained on the record.

An entry

The fields of each object in entries.

tag
The entry’s permanent four-character tag, the way to cite it: “Formal Economics, entry 9A46”.
url
Its page on this site.
kind
Definition, Claim, Lemma, Proposition, Theorem, Example, Problem or Exam question, as the source names it.
number
The printed number, for a problem or a question.
titlename
Its title, and the name economists know it by, where it has one.
status
checked; corrected (the printed sentence is kept word for word, a counterexample shows the condition it needs, and the statement with that condition is proved); open; not-formal.
sourcelocatorpages
Which source states it (an id from sources), the author–year locator, and the printed pages.
topictopics
Its topic in the handbook (an id from topics), and any topics it is cross-listed under.
parts
The printed parts (a), (b), … Each lists its statements, each with a role (Machine-checked, As printed, Counterexample, Corrected statement), a title, the statement, its assumptions (an added condition is flagged), and the conclusion.

Walras’ law

Entry 9A46, as it appears in catalogue.json

  "tag": "9A46",
  "url": "https://formal-economics.github.io/e/9A46/",
  "kind": "Claim",
  "title": "Walras’ law",
  "name": "Walras’ law",
  "status": "checked",
  "source": "rubinstein-lecture-notes",
  "locator": "Rubinstein, Lecture 5, p. 70",
  "pages": "70",
  "topic": "demand",
  "parts": [
    {
      "statements": [
        {
          "role": "Machine-checked",
          "title": "Walras’ law: monotone consumers exhaust their budget",
          "statement": "Let $\\succsim$ be a monotone preference relation on ${X = \\mathbb{R}^K_+}$, and let ${p_k > 0}$ for all $k$ and ${w > 0}$. If $x$ solves the consumer problem at ${(p,w)}$, then ${p \\cdot x = w}$.",
          "assumptions": [
            {
              "text": "$\\succsim$ is a preference relation on ${X = \\mathbb{R}^K_+}$."
            },
            {
              "text": "$\\succsim$ is monotone."
            },
            {
              "text": "Prices are strictly positive, ${p_k > 0}$ for every $k$, and wealth is positive, ${w > 0}$."
            },
            {
              "text": "$x$ solves the consumer problem at ${(p,w)}$."
            }
          ],
          "conclusion": "${p \\cdot x = w}$."
        }
      ]
    }
  ]
}

Citing

Cite an entry by its tag — “Formal Economics, entry 9A46” — and the library as Formal Economics (2026), formal-economics.github.io. Each source keeps its own citation, listed in the bibliography.

The data are regenerated with each edition of the site; an entry’s tag never changes.

How to cite

Every entry has a permanent four-character tag: “Formal Economics, entry M7M6.”

The library: Formal Economics (2026), formal-economics.github.io.

BibTeX 
@misc{formal-economics,
  title        = {Formal Economics: Economic theory, machine-checked},
  howpublished = {\url{https://formal-economics.github.io/}},
  year         = {2026},
  note         = {Every entry is checked by the Lean~4 proof assistant}
}
