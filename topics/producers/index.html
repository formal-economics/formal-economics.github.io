Producers and the firm

A producer is described by a technology, the set of feasible plans, or by a production function. Profit maximization gives the profit and supply functions, with Hotelling’s lemma, and cost minimization gives the cost function.

Results to know

The landmarks of the field, to read first.

  1. Claim Hotelling’s lemma Homogeneity, continuity and convexity of the profit function; its derivative is the supply. Lecture 6, p. 92
  2. Claim Properties of the supply function Homogeneity, continuity and the law of supply. Lecture 6, p. 92
  3. Claim The technology derived from a production function An increasing, continuous, concave production function with f(0) = 0 yields a technology satisfying the standard conditions. Lecture 6, p. 89

Definitions

  1. Technology Production possibilities described by a set of feasible plans, with the standard conditions. Lecture 6, pp. 88–89
  2. Production functions and technologies In the single-output case, a technology and a production function can each be derived from the other. Lecture 6, p. 89
  3. Producer behavior Producers as decision makers with preferences over plans and profits. Lecture 6, p. 90
  4. Profit maximization: profit and supply functions The producer’s problem at given prices, its optimal value and its optimal plan. Lecture 6, p. 91
  5. The cost function The least cost of producing a given output at given input prices. Lecture 6, p. 92

Lecture Notes in Microeconomic Theory

  1. Problem 5. Convex technologies and concave production functions When a technology and a production function describe the same single-output producer, the technology is convex exactly when the production function is concave. Problem Set 6 Easy
  2. Problem 6. Properties of the cost function and Shephard’s lemma Corrected The cost function is homogeneous of degree one and concave in input prices, nondecreasing in the price of an input never used negatively; its derivatives are input demands. Problem Set 6 Easy
  3. Problem 7. The output-maximizing producer with a profit target Corrected A producer who maximizes output subject to earning at least ρ: uniqueness, monotone and continuous supply, and the effect of ρ, each under explicitly stated assumptions. Problem Set 6 Moderately difficult
  4. Problem 8. Information gathering and a non-convex cost function A firm surveys TV viewers in four periods and must pool the answers with one worker; its cost function, computed exactly, is not convex. Problem Set 6 Moderately difficult
  5. Problem 9. A firm that aggregates expert recommendations A firm reports on a 50–50 event using k experts of accuracy p: f(1) = f(2) = p and f(3) = 3p² − 2p³, so production is not concave and the marginal hiring rule can fail. Problem Set 6 Standard
  6. Problem 10. A producer–consumer run by three centers An agent who produces and consumes delegates to three centers: profit maximization delivers his optimum, while maximizing output subject to no loss produces weakly more and leaves him weakly worse off. Problem Set 6 Moderately difficult

MIT 14.121 Microeconomic Theory I

  1. Question 4. A monopolist’s output never rises with marginal cost For any demand curve whatever, a profit-maximizing monopolist with constant unit cost c produces weakly less when c is higher: a pure revealed-preference argument. Problem Set 5
  2. Question 1. Increasing differences Increasing differences survive a non-decreasing change of variable, and h(x − θ) has increasing differences exactly when h is concave. Problem Set 6
  3. Question 2. Pricing against a shifting demand curve Corrected A firm facing demand Q(p, θ) raises its price with θ when log Q has increasing differences, that is, when demand grows more inelastic; concave demand is not necessary for this. Problem Set 6
  4. Question 3. Skill and the choice of technology Increasing differences make computer users buy more skill, and nothing weaker works for every cost of skill; as computers get cheaper, selected skill can jump. Problem Set 6
