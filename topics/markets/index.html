Also relevant, from other fields

  1. Problem 6. The representative consumer Aggregate demand need not behave like the demand of a single rational consumer. Problem Set 5, p. 80 Moderately difficult
  2. Problem 10. A producer–consumer run by three centers An agent who produces and consumes delegates to three centers: profit maximization delivers his optimum, while maximizing output subject to no loss produces weakly more and leaves him weakly worse off. Problem Set 6, p. 97 Moderately difficult
  3. Question 2. An economy with no positive representative consumer With fixed wealth shares, aggregate demand need not be generated by any rational preference: two consumers with kinked utilities produce a violation of the weak axiom. MIT 14.121, Problem Set 4
  4. Question 4. A monopolist’s output never rises with marginal cost For any demand curve whatever, a profit-maximizing monopolist with constant unit cost c produces weakly less when c is higher: a pure revealed-preference argument. MIT 14.121, Problem Set 5
  5. Question 2. Pricing against a shifting demand curve Corrected A firm facing demand Q(p, θ) raises its price with θ when log Q has increasing differences, that is, when demand grows more inelastic; concave demand is not necessary for this. MIT 14.121, Problem Set 6
