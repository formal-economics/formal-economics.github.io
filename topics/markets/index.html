  1. Problem 6. The representative consumer Aggregate demand need not behave like the demand of a single rational consumer. Rubinstein, Problem Set 5, Problem 6, p. 80 Moderately difficult
  2. Problem 10. A producer–consumer run by three centers An agent who produces and consumes delegates to three centers: profit maximization delivers his optimum, while maximizing output subject to no loss produces weakly more and leaves him weakly worse off. Rubinstein, Problem Set 6, Problem 10, p. 97 Moderately difficult 3 parts
  3. Question 2. An economy with no positive representative consumer With fixed wealth shares, aggregate demand need not be generated by any rational preference: two consumers with kinked utilities produce a violation of the weak axiom. MIT 14.121, Problem Set 4, Question 2
