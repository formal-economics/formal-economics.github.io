Behavioral decision theory

Some choice procedures depart from maximizing a single preference, or reach consistent choices by other routes. Examples include Simon’s satisficing, choice with a default and a bias toward it, choice from lists and Luce’s probabilistic choice.

Results to know

The landmarks of the field, to read first.

  1. Claim Satisficing is rationalizable Satisficing choices can always be explained as maximization of some preference relation. Rubinstein, Lecture 3, p. 30
  2. Proposition Characterization of the default-bias procedure On a finite set, the weak axiom and default tendency characterize choice that maximizes utility with a bonus for the default. Rubinstein, Lecture 3, p. 40

Definitions

  1. Satisficing (Simon’s procedure) A decision maker examines alternatives in a fixed order and takes the first satisfactory one. Rubinstein, Lecture 3, pp. 29–30
  2. Choice with a default option Choice problems in which one available alternative is the default. Rubinstein, Lecture 3, p. 38
  3. The default-bias procedure Maximize utility, but give the default a non-negative bonus. Rubinstein, Lecture 3, p. 39
  4. Weak axiom for choice with defaults A revealed-preference consistency condition adapted to choice problems with a default. Rubinstein, Lecture 3, p. 40
  5. Default tendency Promoting the chosen alternative to default does not change the choice. Rubinstein, Lecture 3, p. 40

Results

  1. Problem 7. A money pump · A money pump against someone who believes 2 + 3 = 6 A decision maker who systematically calculates 2 + 3 = 6 can be led through trades that return his holdings but take his money, without limit. Problem Set 7 Food for thought
  2. Problem 3. Preference reversal Informal Many people choose the safer of two bets yet put a higher money value on the riskier one: a discussion of the preference-reversal phenomenon. Problem Set 8 Standard
  3. Problem 5. Adam’s apples Four mild-looking conditions on preferences over apple streams imply that Adam would give up two apples a day from day 4 onward for a single apple today. Problem Set 8 Standard
  4. Problem 6. Yaari’s dual theory · Yaari’s dual expected utility Yaari’s dual functional induces a preference that may violate independence, and weighting each prize’s own probability can even violate first-order stochastic dominance. Problem Set 8 Moderately difficult
  5. Question 4. Do survey answers reveal preferences? Informal A discussion question on contingent valuation: which preference axioms might survey answers violate, and how could a survey test for such violations? MIT 14.121 · Problem Set 1

Also relevant, from other fields

  1. Satisficing satisfies condition α The satisficing procedure produces choices consistent with condition α. Claim Rubinstein, Lecture 3, p. 29
  2. Satisficing is rationalizable Satisficing choices can always be explained as maximization of some preference relation. Claim Rubinstein, Lecture 3, p. 30
  3. Dushnik–Miller theorem · Multiple criteria and incomplete preferences Comparing alternatives by unanimity over several complete rankings yields exactly the asymmetric, transitive relations on a finite set. Problem Rubinstein, Problem Set 1, Problem 5, p. 11
  4. The Shepard scale Informal An auditory illusion of an endlessly rising scale, offered as an analogy for intransitive comparisons. Problem Rubinstein, Problem Set 1, Problem 6, p. 11
  5. Representing “approximately the same” Six axioms for a similarity relation on the unit interval reduce it to closeness within a fixed tolerance after a continuous, increasing rescaling. Problem Rubinstein, Problem Set 2, Problem 6, p. 22
  6. Is the procedure rational? Five verbal decision procedures, each tested against the choice model and the rational man paradigm. Problem Rubinstein, Problem Set 3, Problem 1, p. 44
  7. Choosing from the most common class A procedure that picks the best member of the most frequent class is consistent on pairs but need not be rational. Problem Rubinstein, Problem Set 3, Problem 4, p. 45
  8. Threshold procedures (Kalai, Rubinstein and Spiegler) Two procedures that switch between two criteria at a threshold: one is always rationalizable, the other need not be. Problem Rubinstein, Problem Set 3, Problem 5, p. 45
  9. Choice from lists (Rubinstein and Salant) When alternatives arrive as a list, order and repetition can matter; Property I with Duplication Invariance brings back rational choice. Problem Rubinstein, Problem Set 3, Problem 6, pp. 45–46
  10. Lexicographically rational choice (Rubinstein and Salant) Choice guided by the most notable alternative on the menu is characterized by a reference-point property. Problem Rubinstein, Problem Set 3, Problem 7, pp. 46–47
  11. Choice by rationales (Cherepanov, Feddersen and Sandroni) Choosing the best of the alternatives one can rationalize is characterized by a weak form of the weak axiom; the warm-glow procedure is an example. Problem Rubinstein, Problem Set 3, Problem 8, p. 47
  12. Luce’s choice axiom · Luce's choice axiom Corrected statement Path independence of choice probabilities forces the Luce model, in which each alternative is chosen with probability proportional to a fixed weight. Problem Rubinstein, Problem Set 3, Problem 9, p. 47
  13. A consumer with a utility floor Corrected statement Securing a utility floor and then maximizing the amount of good 1 is rationalizable, spends all wealth and gives continuous demand; a closed floor set ensures a unique choice. Problem Rubinstein, Problem Set 5, Problem 5, p. 80
  14. Saving as a residual decision Corrected statement Saving what is left after pursuing an aspiration level is fully rationalizable where choice is unique, but for some value functions by no continuous or differentiable preference. Problem Rubinstein, Problem Set 5, Problem 9, p. 81
  15. Two procedural preferences over lotteries Ranking lotteries by the size of their support violates both the independence and the continuity axioms, ranking them by their most likely prize can violate both, and each is exposed to framing. Problem Rubinstein, Problem Set 7, Problem 1, p. 110
  16. Betweenness and the Allais paradox · The betweenness axiom Betweenness follows from independence, means straight but not necessarily parallel indifference lines, and is compatible with the Allais paradox. Problem MIT 14.121, Problem Set 2, Question 3
