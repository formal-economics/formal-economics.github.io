Also relevant, from other fields

  1. Problem 9. A firm that aggregates expert recommendations A firm reports on a 50–50 event using k experts of accuracy p: f(1) = f(2) = p and f(3) = 3p² − 2p³, so production is not concave and the marginal hiring rule can fail. Problem Set 6, p. 96 Standard
  2. Problem 8. Who pays more for information? Is a more risk-averse agent ready to pay more to learn the state of nature? Under expected utility it could go either way, and both cases are exhibited. Problem Set 8, p. 127
