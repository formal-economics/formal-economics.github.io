    Indifference classes form a partition

    Let ≿ be a preference relation on X and let I(x) be the set of all y∈X with y∼x. Show that {I(x):x∈X} is a partition of X: for all x and y, either I(x)=I(y) or I(x)∩I(y)=∅; and every x∈X belongs to some I(y).

    RubinsteinProblem Set 1

    Standard

    Answer machine-checked

    Kreps's definition of preferences

    Kreps (1990) takes as primitive a relation P, read “strictly preferred”, and requires asymmetry (for no x,y both xPy and yPx) and negative transitivity (if xPy, then for any z, xPz or zPy). Explain the sense in which this formalization is equivalent to the traditional definition of a preference relation.

    Answer

    Proved: both translations, and both round trips, hold pointwise for all x,y. The two primitives carry exactly the same information.

  3. Problem 3

    RubinsteinProblem Set 1

    Difficult

    Answer machine-checked

    Ranking menus (Kannai and Peleg)

    Let Z be a finite set and X the set of nonempty subsets of Z; a set A∈X is a menu from which the agent will later choose, and ≿ is a preference relation on X. Property 1: if A≿B and C is disjoint from both, then A∪C≿B∪C, and likewise with ≻. Property 2: if x∈Z and {x}≻{y} for all y∈A, then A∪{x}≻A; if {y}≻{x} for all y∈A, then A≻A∪{x}.

    1. (a)

      Discuss the plausibility of the two properties.

      No machine-checked answer for this part.

    2. (b)

      Give examples of preference relations that (i) satisfy both properties, (ii) satisfy the first but not the second, (iii) satisfy the second but not the first.

      Answer

      Yes: an example exists (part (b)(i)).

    3. (c)

      Show that if {x}≻{y}≻{z} for some x,y,z∈Z, no preference relation satisfies both properties.

      Answer

      Proved: under a strict chain of three singletons, Property 1 and Property 2 cannot both hold. It is a version of the impossibility theorem of Kannai and Peleg (1984).

  5. Problem 5

    RubinsteinProblem Set 1

    Difficult

    Answer machine-checked

    Multiple criteria and incomplete preferences

    A decision maker’s attitude toward a finite set X is an asymmetric, transitive, possibly incomplete relation ≻. An author assumes more: the decision maker has n criteria, each a complete ordering ≻i​, and x≻y iff x≻i​y for every i.

    1. (1)

      Verify that the relation generated this way is asymmetric and transitive, and argue that the procedure is sometimes a reasonable description.

      Answer

      Proved, for any set X (finiteness of X is not needed). Completeness of ≻ is not part of the statement; it fails as soon as two criteria disagree.

    2. (2)

      The additional assumption is claimed to be vacuous: every asymmetric, transitive relation arises this way. Demonstrate it for X={a,b,c} with only a≻b.

      Answer

      Proved: such orderings exist. One pair that works is a≻1​b≻1​c and c≻2​a≻2​b: they agree only on a over b.

    3. (3)

      Prove the claim in general (the main part of the question).

      Answer

      Proved: the multiple-criteria assumption adds nothing beyond asymmetry and transitivity on a finite set. This is the finite case of the Dushnik–Miller theorem.

  7. Problem 1

    RubinsteinProblem Set 2

    Easy

    Answer machine-checked

    Utility representation and continuity

    1. (a)

      Is it correct that if U and V both represent ≿, then V(x)=f(U(x)) for some strictly monotonic f:R→R?

      No machine-checked answer for this part.

    2. (b)

      Can a continuous preference relation be represented by a discontinuous utility function?

      No machine-checked answer for this part.

    3. (c)

      Show that on X=R the preference represented by u(x)=⌊x⌋ is not continuous.

      No machine-checked answer for this part.

    4. (d)

      Show that the definitions C1 and C2 of continuity are equivalent to C3 (the sets {y:y≿x} and {y:x≿y} are closed for every x) and to C4 (the sets {y:y≻x} and {y:x≻y} are open for every x).

      No machine-checked answer for this part.

    Answer

    (a) No: the claim is refuted, even allowing f to be strictly increasing or strictly decreasing. (b) Yes: a continuous preference can have a discontinuous representation. (c) Proved: the floor-function preference is not continuous. (d) Proved: C1 is equivalent to C3 and to C4, and with C1 ⟺ C2 from the lecture all four definitions coincide.

    Integer-valued utility on a countable set

    Give an example of preferences over a countable set that cannot be represented by a utility function taking only integer values.

    Answer

    Proved: such an example exists. One example of this kind is the set of rationals with its usual order: between 0 and 1 lie infinitely many rationals, more than the finitely many integers strictly between u(0) and u(1).
