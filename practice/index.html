Problems with checked answers

Practise on problems from a textbook, a PhD course and a qualifying exam.

  1. Problem 1Rubinstein · Problem Set 1Easy

    Indifference classes form a partition

    Take a preference relation ≿ on X. For each x, write I(x) for the collection of y∈X such that y∼x. Prove that {I(x):x∈X} partitions X. That is, any two of these sets are equal or disjoint (I(x)=I(y) or I(x)∩I(y)=∅), and each x∈X lies in at least one I(y).

    Answer

    Proved for every preference relation on every set X, in exactly the two-clause sense of partition that the problem spells out.

  2. Problem 2Rubinstein · Problem Set 1Standard

    Kreps's definition of preferences

    In Kreps (1990) the primitive is a relation P, interpreted as strict preference. Two axioms are imposed. Asymmetry: xPy and yPx never hold together. Negative transitivity: whenever xPy, every z satisfies xPz or zPy. In what sense does this approach match the standard definition of a preference relation? Explain.

    Answer

    Proved: both translations, and both round trips, hold pointwise for all x,y. The two primitives carry exactly the same information.

  3. Problem 3Rubinstein · Problem Set 1Difficult

    Ranking menus (Kannai and Peleg)

    Fix a finite set Z. Let X consist of the nonempty subsets of Z. Think of A∈X as a menu; the agent picks an item from it at a later date. A preference relation ≿ is given on X. Property 1: whenever A≿B and C meets neither A nor B, we get A∪C≿B∪C; the same holds for ≻. Property 2: take x∈Z. If {x}≻{y} holds for each y∈A, then A∪{x}≻A. If instead {y}≻{x} holds for each y∈A, then A≻A∪{x}.

    1. a

      How reasonable is each property? Discuss.

      Not a formal statement

    2. b

      Find preference relations that (i) meet both properties, (ii) meet Property 1 but fail Property 2, (iii) meet Property 2 but fail Property 1.

      Answer

      Yes: an example exists (part (b)(i)).

    3. c

      Suppose some x,y,z∈Z have {x}≻{y}≻{z}. Prove that then no preference relation has both properties.

      Answer

      Proved: under a strict chain of three singletons, Property 1 and Property 2 cannot both hold. It is a version of the impossibility theorem of Kannai and Peleg (1984).

    Full solution →

  4. Problem 4Rubinstein · Problem Set 1Moderately difficult

    Extending an acyclic relation to an ordering

    Take a finite set X and an asymmetric relation ≻ on it with no cycles; that is, no chain x1​≻x2​≻⋯≻xK​≻x1​ exists with K>2. Using induction on the number of elements of X, prove that some complete ordering (complete, asymmetric, transitive) contains ≻.

    Answer

    Proved: such an extension ≻′ always exists.

  5. Problem 5Rubinstein · Problem Set 1Difficult

    Multiple criteria and incomplete preferences

    On a finite set X, a decision maker’s attitude is captured by a relation ≻ that is asymmetric and transitive but need not be complete. One author goes further. He supposes the decision maker uses n criteria, each one a complete ordering ≻i​, and that x≻y holds exactly when x≻i​y for all i.

    1. 1

      Check that a relation built in this manner is asymmetric and transitive. Explain why the procedure can at times describe behaviour well.

      Answer

      Proved, for any set X (finiteness of X is not needed). Completeness of ≻ is not part of the statement; it fails as soon as two criteria disagree.

    2. 2

      It is said that the extra assumption costs nothing, since each asymmetric, transitive relation can be built this way. Show this for X={a,b,c} when the only ranking is a≻b.

      Answer

      Proved: such orderings exist. One pair that works is a≻1​b≻1​c and c≻2​a≻2​b: they agree only on a over b.

    3. 3

      Establish the general claim. This is the core of the problem.

      Answer

      Proved: the multiple-criteria assumption adds nothing beyond asymmetry and transitivity on a finite set. This is the finite case of the Dushnik–Miller theorem.

    Full solution →

  7. Problem 1Rubinstein · Problem Set 2Easy

    Utility representation and continuity

    1. a

      Suppose U and V are two utility functions for ≿. Must there exist a strictly monotonic f:R→R such that V(x)=f(U(x))?

    2. b

      May a utility function for a continuous preference relation fail to be continuous?

    3. c

      Take X=R and the utility u(x)=⌊x⌋. Prove that the preference it induces fails continuity.

    4. d

      Prove that continuity in the sense of C1 or C2 holds exactly when C3 holds (for each x, both {y:y≿x} and {y:x≿y} are closed), and exactly when C4 holds (for each x, both {y:y≻x} and {y:x≻y} are open).

    Answer

    (a) No: the claim is refuted, even allowing f to be strictly increasing or strictly decreasing. (b) Yes: a continuous preference can have a discontinuous representation. (c) Proved: the floor-function preference is not continuous. (d) Proved: C1 is equivalent to C3 and to C4, and with C1 ⟺ C2 from the lecture all four definitions coincide.

    Full solution →

  8. Problem 2Rubinstein · Problem Set 2Moderately difficult

    Integer-valued utility on a countable set

    Find a preference relation on a countable set for which no integer-valued utility function exists.

    Answer

    Proved: such an example exists. One example of this kind is the set of rationals with its usual order: between 0 and 1 lie infinitely many rationals, more than the finitely many integers strictly between u(0) and u(1).

    Full solution →

  9. Problem 3Rubinstein · Problem Set 2Easy

    Indifference along a segment

    Assume ≿ is a continuous preference relation on X⊆Rn, and that the line segment from x to z lies inside X. Prove: when x≿y≿z, some m on this segment satisfies y∼m.

    Answer

    Proved. Nothing is assumed of X beyond containing the one segment — no convexity, and no condition such as x=z or x≻z.
