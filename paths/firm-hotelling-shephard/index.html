The firm: from technologies to Hotelling’s and Shephard’s lemmas

Technologies and production functions, profit and supply, cost, and comparative statics without calculus

A producer is described by its set of feasible plans or, with a single output, by a production function. Maximizing profit gives the profit and supply functions, minimizing cost gives the cost function, and in both cases a supporting-plane argument makes the derivative of the value function equal to the optimal plan. The path ends with comparative statics that need no derivatives.

  1. 1

    Definition · Rubinstein, Lecture 6, pp. 88–89

    Technology

    A technology is a set Z⊆RK of feasible plans, with outputs positive and inputs negative. The standard conditions are inaction, no output without inputs, free disposal, closedness and convexity.

    Definition

    A technology is a set Z⊆RK of production combinations; positive components are outputs and negative components inputs. Conditions that may be imposed:

    1. 0∈Z: inaction is possible;
    2. no production without resources: no z∈Z∩R+K​ other than 0;
    3. free disposal: z∈Z and z′≤z imply z′∈Z;
    4. Z is closed;
    5. Z is convex.

    If Z is convex and 0∈Z, then λz∈Z for every z∈Z and every λ∈[0,1).

    Definition · Rubinstein, Lecture 6, p. 89

    Production functions and technologies

    With a single output, a technology defines a production function f(v)=max{x:(−v,x)∈Z}, the largest output from the inputs v, and a production function defines a technology in turn.

    Definition

    Consider the single-output case: commodity K is produced from commodities 1,…,K−1, i.e. every z∈Z has zK​≥0 and zk​≤0 for k=K.

    1. From a technology Z, the production function is f(v)=max{x:(−v,x)∈Z} for input vectors v∈R+K−1​.
    2. From a production function f, the derived “technology” is Z(f)={(−w,x):x≤f(v) and w≥v for some v∈R+K−1​}.

    Problem · Rubinstein, Problem Set 6, Problem 5, p. 95

    Convex technologies and concave production functions

    When a technology and a production function describe the same producer, the technology is convex exactly when the production function is concave.

    The question

    A technology Z and a production function f describe the same producer, who produces commodity K from inputs 1,…,K−1. Show that Z is a convex set if and only if f is a concave function.

    Claim · Rubinstein, Lecture 6, p. 92

    Properties of the supply function

    Claim · Rubinstein, Lecture 6, p. 92

    Hotelling’s lemma

    Hotelling’s lemma: p⋅z(p∗)≤π(p) for every p, with equality at p∗, so if π is differentiable, and the maximum is attained at nearby prices, ∂π/∂pk​(p∗)=zk​(p∗). The profit function is homogeneous of degree one and convex.

  8. 8

    Problem · Rubinstein, Problem Set 6, Problem 6, p. 95

    Shephard’s lemma

    Shephard’s lemma: where the cost function has a partial derivative in the price of input k, and is defined at nearby prices, that derivative is the amount of input k in every cost-minimizing input vector. Cost is also homogeneous of degree one and concave in input prices, and nondecreasing in the price of an input never used in a negative amount, a condition added to the printed problem.

    Problem · MIT 14.121, Problem Set 5, Question 4

    A monopolist’s output never rises with marginal cost

    Comparative statics with no assumption on demand: a profit-maximizing monopolist with constant unit cost c produces weakly less when c is higher. Each plan is at least as profitable as the other at its own cost, the argument behind the law of supply.

    Problem · MIT 14.121, Problem Set 6, Question 3

    Skill and the choice of technology

    Increasing differences: if G−H is non-decreasing in skill, the largest profit-maximizing skill with technology G is at least that with H whenever both exist, for every cost of skill, and no weaker condition does this for every cost. As the new technology gets cheaper, the skill firms select can still jump.
