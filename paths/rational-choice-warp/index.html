Rational choice: from choice functions to the weak axiom

When can observed choices be explained by maximizing one preference?

Begin with step 1 → Advanced undergraduateAbout 45 minutes

The route

  1. Choice function
  2. Rational choice function
  3. Rationalizable choice
  4. Condition α
  5. Rational choice satisfies condition α
  6. Rationalizability of choice functions satisfying condition α
  7. Choice correspondence
  8. Weak axiom of revealed preference (choice correspondences)
  9. Condition α (choice correspondences)
  10. Condition β (choice correspondences)
  11. Rationalizability by α and β
  12. The weak axiom (WARP)

Two consistency conditions carry this guide. On suitable domains, condition α is exactly what single choices need to be explained by a preference, condition β joins it once ties are allowed, and at the end the two together turn out to be a single familiar axiom.

  1. 1

    Rubinstein, Lecture 3, p. 24

    Step 1: Choice function

    The guide begins with what can be observed, a choice from each menu, and asks nothing about the motives behind it.

    Read the definition

    Given a context (X,D), a choice function C assigns to every A∈D an element C(A)∈A.

  2. 2

    Rubinstein, Lecture 3, p. 25

    Step 2: Rational choice function

    Next, the benchmark that every later condition is tested against: choice made by maximizing one fixed preference.

    Read the definition

    Let (X,D) be a context and ≿ a preference relation on X, and assume that every A∈D has a unique best element under ≿, an a∈A with a≿x for all x∈A. The induced (rational) choice function C≿​ assigns to each A∈D its best element under ≿.

  3. 3

    Rubinstein, Lecture 3, p. 27

    Step 3: Rationalizable choice

    With behaviour on one side and the benchmark on the other, the guide’s question can be stated precisely: when does a choice function agree with the benchmark for some preference?

    Read the definition

    A choice function C for a context (X,D) can be rationalized if there is a preference relation ≿ on X such that every A∈D has a unique best element under ≿ and C(A)=C≿​(A) for every A∈D.

  4. 4

    Rubinstein, Lecture 3, p. 27

    Step 4: Condition α

    The first consistency condition, stated in terms of choices alone, so that it can be checked against data.

    Read the definition

    A choice function C for a context (X,D) satisfies condition α if for all A,B∈D with A⊂B and C(B)∈A, we have C(A)=C(B).

  5. 5

    Rubinstein, Lecture 3, p. 27

    Step 5: Rational choice satisfies condition α

    This makes α a test: a choice function that violates it cannot come from maximizing a preference.

    Read the claim

    Let (X,D) be a context and ≿ a preference relation on X such that every A∈D has a unique best element under ≿. Then the induced choice function C≿​ satisfies condition α.

  6. 6

    Rubinstein, Lecture 3, p. 28

    Step 6: Rationalizability of choice functions satisfying condition α

    Here the test becomes an answer: if the domain includes every menu of up to three alternatives, passing α is enough.

    Read the proposition

    Let C be a choice function for a context (X,D) in which D contains every nonempty subset of X with at most three elements. If C satisfies condition α, then C can be rationalized: there is a preference relation ≿ on X with C=C≿​ on D.

    Try it
  7. 7

    Rubinstein, Lecture 3, p. 31

    Step 7: Choice correspondence

    Decision makers are often indifferent, so the guide now lets a choice be a set of acceptable alternatives rather than a single one.

    Read the definition

    Given a context (X,D), a choice correspondence C assigns to every A∈D a set C(A) with ∅=C(A)⊆A.

  8. 8

    Rubinstein, Lecture 3, p. 32

    Step 8: Weak axiom of revealed preference (choice correspondences)

    The best-known consistency condition for choice with ties; the rest of the guide splits it into two simpler conditions.

    Read the definition

    A choice correspondence C for a context (X,D) satisfies the weak axiom (WA) if for all A,B∈D and all x,y∈A∩B: if x∈C(A) and y∈C(B), then x∈C(B).

  9. 9

    Rubinstein, Lecture 3, p. 33

    Step 9: Condition α (choice correspondences)

    The first of the two is condition α again, adapted to sets of choices: it looks at what happens when a menu shrinks.

    Read the definition

    A choice correspondence C for a context (X,D) satisfies condition α if for all A,B∈D with A⊂B and every a∈A: if a∈C(B), then a∈C(A).

  10. 10

    Rubinstein, Lecture 3, p. 33

    Step 10: Condition β (choice correspondences)

    The second, condition β, looks the other way, at what happens when a menu grows.

    Read the definition

    A choice correspondence C for a context (X,D) satisfies condition β if for all A,B∈D with A⊂B and all a,b∈A: if a,b∈C(A) and b∈C(B), then a∈C(B).

  11. 11

    Rubinstein, Lecture 3, pp. 33–34

    Step 11: Rationalizability by α and β

    Together the two do for choice with ties what α alone did for single choices, again provided every menu of up to three alternatives is in the domain.

    Read the proposition

    Let C be a choice correspondence for a context (X,D) in which D contains every nonempty subset of X with at most three elements. If C satisfies conditions α and β, then there is a preference relation ≿ on X such that C≿​(A) is nonempty and C(A)=C≿​(A) for every A∈D.

  12. 12

    Rubinstein, Lecture 3, p. 33

    Step 12: The weak axiom (WARP)

    The destination, and the reason the weak axiom came first: on domains closed under intersection it is the two conditions in one.

    Read the claim

    Let C be a choice correspondence for a context (X,D) in which A∩B∈D whenever A,B∈D and A∩B=∅. Then C satisfies conditions α and β if and only if C satisfies WA.

Where to go next

For demand functions, the weak axiom together with Walras’ law gives the compensated law of demand.
