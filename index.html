    Arrow’s impossibility theorem

    Machine-checked in Lean 4 · the proof runs 45 lines and cites 8 results of the library

    Let N be a finite set of individuals and let X contain at least three alternatives. If a social welfare function F satisfies Par and IIA, then F is dictatorial: there is an individual i∗ such that for every profile and all x,y∈X, society strictly prefers x to y if and only if x≻i∗​y.

    The assumptions of Arrow’s impossibility theorem as the source states them, each beside the line of the Lean statement that states it.
    Number As the source states it As Lean states it Matches the source
    theorem arrow_impossibility {X N : Type*}
    1 N is a finite set of individuals. [Finite N]
    2 F is a social welfare function: at every profile its value is a complete, reflexive and transitive social preference. (F : SWF X N)
    3 ∣X∣≥3: there are three distinct alternatives. (hX : ∃ a b c : X, a ≠ b ∧ a ≠ c ∧ b ≠ c)
    4 Par: if every individual strictly prefers x to y, so does society. (hPar : Par F)
    5 IIA: the social ranking of x and y depends only on how the individuals rank x against y. (hIIA : IIA F)
    ⇒ F is dictatorial.Dictatorial F

    each assumption is one the source states; the Lean statement assumes nothing more.

    The practice room
    1. 1. May’s theorem Based on May (1952). The set of social alternatives X has only two elements. A social welfare function (SWF) attaches a preference to every profile of preferences; indifference is allowed for individuals and for society. Consider the axioms: Rubinstein, Problem Set 9, Problem 2, p. 136 Moderately difficult 3 parts Answer machine-checked
    2. 2. Second-order stochastic dominance Based on Rothschild and Stiglitz (1970). Say that p second-order stochastically dominates q, written pD2​q, if p≿q for every preference ≿ satisfying the vNM assumptions, monotonicity and risk aversion. Rubinstein, Problem Set 8, Problem 2, p. 125 Standard 3 parts Answer machine-checked
    3. 3. Szpilrajn’s extension theorem Let ≻ be an asymmetric relation on a finite set X that has no cycle: there is no sequence x1​≻x2​≻⋯≻xK​≻x1​ with K>2. Show, by induction on the size of X, that ≻ can be extended to a complete ordering (a complete, asymmetric and transitive relation). Rubinstein, Problem Set 1, Problem 4, p. 11 Moderately difficult Answer machine-checked

    Use it in your own Lean project

    Every entry is a Lean 4 declaration you can import and build on. Add the library as a dependency named rubinstein (Lean 4.31 with Mathlib), then use its theorems in your own models: 

    import Rubinstein.Lecture05.WalrasLaw

open Rubinstein.Lecture01 Rubinstein.Lecture04 Rubinstein.Lecture05

-- Walras' law, ready for your own model
example {K : ℕ} (pref : WeakPreference ↥(nonnegOrthant K))
    (hmono : pref.IsMonotone) (p : Fin K → ℝ) (hp : ∀ k, 0 < p k)
    (w : ℝ) (hw : 0 < w) (x : ↥(nonnegOrthant K))
    (hx : pref.IsBestIn (budgetSet p w) x) :
    ∑ k, p k * x.val k = w :=
  walras_law pref hmono p hp w hw x hx
